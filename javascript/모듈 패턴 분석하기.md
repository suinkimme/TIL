## 모듈 패턴을 이용한 private 변수 구현 분석하기

```javascript
const createCounter = () => {
  // 클로저를 이용한 private 변수
  let count = 0;

  return {
    increment: () => {
      count++;
      console.log(`Count: ${count}`);
    },
    decrement: () => {
      count--;
      console.log(`Count: ${count}`);
    },
    getCount: () => count
  };
};

const counter = createCounter();
counter.increment(); // Count: 1
counter.increment(); // Count: 2
counter.decrement(); // Count: 1
console.log(counter.getCount()); // 1
console.log(counter.count); // undefined
```

### 제공된 자료의 설명

> 이 예제에서 `createCounter` 함수의 렉시컬 환경은 `count` 변수를 포함합니다. 반환된 객체의 메서드들은 이 렉시컬 환경에 대한 클로저를 형성하여 `count`에 접근할 수 있지만, 외부에서는 직접 접근할 수 없습니다.

### 내가 공부한 것

#### 모듈 패턴 

- 어떤 기능을 캡슐화해서, 내부 구현은 숨기고 외부엔 필요한 것만 공개하는 구조.
- 자바스크립트에서 `클로저(closure)`를 이용해서 이걸 구현함

#### 클로저 (Closure)

- 함수가 자기 외부 스코프의 변수를 기억하고 참조할 수 있는 것.

> `createCounter` 함수 안에 있는 `count`는 밖에서 절대 접근할 수 없다. 하지만 반환된 객체의 `increment`, `decrement`, `getCount`는 모두 이 `count`를 기억하는 클로저이므로 이 메서드들을 통해서만 `count`를 조작할 수 있다.
