## 콜백함수와 제어권

### 콜백함수란?

- 다른 코드의 인자로 넘겨주는 함수다.
- 콜백 함수를 넘겨 받은 함수, 메서드(예: `forEach`, `setTimeout`) 등은 이 콜백 함수를 필요에 따라 적절한 시점에 실행하게 된다.
- 함수 또는 메서드에게 인자로 넘겨줌으로써 그 제어권도 함께 위임한다.
- 콜백 함수를 위임받은 함수 또는 메서드는 자체적으로 내부 로직에 의해 이 콜백 함수를 적절한 시점에 실행한다.
  > 이 적절한 시점 역시 제어권이 있는 위임받은 코드가 알아서 한다.

### 제어권

> 위임 받은 코드가 얻게되는 제어권에 대한 설명이다.

#### 1. 호출 시점에 대한 제어권

```javascript
var count = 0;
var cbFunc = function () {
  console.log(count);
  if (++count > 4) {
    clearInterval(timer);
  }
};

// 예: 1. 고차함수(setInterval)가 제어권을 갖게 되는 경우
var timer = setInterval(cbFunc, 1000);

// 예: 2. 사용자가 제어권을 갖게 되는 경우
cbFunc();
```

> **예: 1**<br>`setInterval`에게 매개변수로 함수를 넘겨줬기(위임했기) 때문에 해당 함수(콜백함수)의 제어권은 `setInterval`에 있다.<br>제어권이 `setInterval`에게 있기 때문에 1초 마다 콜백 함수가 실행된다.(사용자 제어권 잃음)

> **예: 2**<br>즉시 실행했기 때문에 해당 함수의 제어권은 사용자에게 있다.

- 원래 `cbFunc()`를 수행한다면 그 호출 주체와 제어권은 모두 사용자가 된다.
- `setInterval`로 넘겨주게 되면 그 호출 주체와 제어권은 모두 setInterval이 된다.

#### 2. 인자에 대한 제어권

```javascript
var newArr = [10, 20, 30].map(function (currentValue, index) {
  return currentValue + 5;
});

console.log(newArr); // [15, 25, 35]

var newArr2 = [10, 20, 30].map(function (index, currentValue) {
  return currentValue + 5;
});

console.log(newArr2) // [5, 6, 7]
```

- `currentValue`, `index`는 사람이 이해할 수 있는 값일 뿐이다.
    - 컴퓨터가 인식하는 것은 매개 변수의 위치다.
- 사전에 정의된 콜백 함수를 위임하는 함수 또는 메서드를 사용해서 원하는 값을 얻고자 할 때 사용법 그대로 사용해야한다.
    - 즉, 인자에 대한 제어권은 위임 받는 함수만이 인자에 대한 제어권을 갖고 있는 것이다. 결과적으로 인자의 순서까지 귀속 되어있다.

### 3. this

콜백 함수도 함수이기 때문에 기본적으로 `this`가 전역객체를 참조한다. 하지만 예외 사항도 있다.

> 제어권을 넘겨 받을 함수 또는 메서드에 별도로 `this`가 될 대상을 지정한 경우에는 그 대상을 참조한다.

#### <`map`을 직접 구현하며 콜백 함수에 `this` 지정하기>

```javascript
Array.prototype.map2 = function (callback, thisArg) {
  var mappedArr = [];

  for (var i = 0; i < this.length; i++) {
    var mappedValue = callback.call(thisArg || window, this[i]);
    mappedArr[i] = mappedValue;
  }

  return mappedArr;
};

var newArr = [1, 2, 3].map2(function (number) {
  return number * 2;
});

console.log(newArr); // [2, 4, 6]
```

모양은 좀 다르지만 `[1, 2, 3]`이 객체가 되고, `map2` 메서드를 호출한 것이다. 즉, **메서드 호출 방식**이라고 볼 수 있고 메서드 호출 방식은 `this`가 그 객체를 바라보게 된다.
