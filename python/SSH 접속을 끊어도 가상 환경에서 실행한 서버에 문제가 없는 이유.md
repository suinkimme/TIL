## 문제

SSH 접속을 끊었지만, 가상 환경에서 `nohup`로 실행한 파이썬 서버가 계속 실행됨.

## 상황

```shell
# 1. 가상환경 활성화
source .venv/bin/activate

# 2. 백그라운드에서 실행
nohup python app.py &
```

이 상태에서 SSH를 종료(exit)해도 서버가 계속 실행됨.

## 해결

Python 가상환경(`venv`)은 특정 디렉토리에 설치된 Python 및 라이브러리를 사용하는 일종의 환경 설정 도구다.

#### 접속을 끊어도 프로세스가 유지된 이유

1. `nohup`이 프로세스를 백그라운드에서 유지하기 때문
2. Python 프로세스가 실행될 때 이미 가상환경이 로드되었기 때문

실행된 프로세스는 독립적으로 동작함, 즉 가상환경 자체가 유지되는 것이 아님, 가상환경에서 실행된 Python 프로세스가 계속 실행 중이기 때문임.
