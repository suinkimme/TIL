## Python의 가상환경(venv)과 사용법

- 프로젝트를 진행하다 보면 여러 모듈을 설치하게 됨.
- 서로 의존성(dependency)을 가지는 경우가 많음.
- 때문에, 글로벌 단위로 모듈을 설치하면 여러 프로젝트 관리가 어려움.
  - 프로젝트 1 요구사항 : A 패키지: 1.x
  - 프로젝트 2 요구사항 : A 패키지: 2.x
- 따라서, 각각의 프로젝트에 필요한 모듈을 별도로 설치하여 사용하게됨.
- 이를 **가상환경**이라고 함.

> node package는 글로벌과 지역을 나누어 설치할 수 있지만, 파이썬의 **pip는 무조건 글로벌 환경**에 설치함 때문에 **별도로 가상환경이라는 개념을 적용**하게 됨.

초창기 파이썬에서는 가상환경을 공식적으로 지원해주지 않았으나, 현재는 지원해줌<br/>
따라서 가상환경의 종류가 많으나 오늘은 **venv**만 알아보도록 하겠음.

### venv 사용법

venv의 모든 명령어는 프로젝트의 루트 디렉토리 터미널에서 실행시켜주어야 한다.

#### 1. 가상환경 생성

```shell
python3 -m venv {가상환경이름}
```

가상환경이 잘 생성 되었다면 루트 디텍토리에 해당 이름으로 폴더가 생성됨.<br>
일반적으로 가상환경 이름은 .venv로 정하는게 관례임.

```shell
# 가상환경 설정으로 생성된 폴더 내부
.venv
ㄴ bin
ㄴ include
ㄴ lib # 패키지가 설치되는 폴더
ㄴ pyvenv.cfg
```

#### 2. 가상환경 활성화

실행할 가상환경 이름을 명시해주고 명렁어를 실행함.<br>
이름을 명시한다는 것은 하나의 루트 디렉토리에 여러 개의 가상환경을 만들고, 원하는 환경을 활성화하여 프로그램을 실행할 수도 있다는 것.

```shell
source .venv/bin/activate # .venv는 본인이 설정한 가상환경 이름으로 대체될 수 있음.
```

가상환경이 활성화되면 프롬프트의 앞부분이 가상환경 directory의 이름이 된다.

```shell
~/d/s/j/p/prac_python # ~/dev/study/jungle/practice/prac_python의 경로로 인해 만들어진 이름
```

#### 3. 가상환경에 모듈(패키지) 설치

글로벌 환경에 설치하는 것과 같이 설치를 진행하면 가상환경 내에 설치된다.

```shell
# numpy 설치 예시
pip install numpy
```

#### 4. 가상환경 비활성화

```shell
deactivate
```

#### 5. 가상환경 삭제

가상환경 폴더를 지우면, 환경 또한 삭제된다.
