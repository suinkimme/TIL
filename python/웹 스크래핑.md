## 웹 스크래핑

> 웹 페이지에서 우리가 원하는 부분의 데이터를 수집해오는 것을 뜻함

크롤링(crawling)과 혼용해서 쓰는 경우가 있으나, 크롤링은 자동화하여 주기적으로 웹 상에서 페이지들을 돌아다니며 분류/색인하고 업데이트된 부분을 찾는 것이다.

### 직접 해보기

#### 1. 필요한 패키지 설치

```shell
pip install requests # API 요청
pip install bs4 # HTML 구조 파악
```

#### 2. 새 파이썬 파일을 만들어 코드 작성

```python
import requests
from bs4 import BeautifulSoup

# 타겟 URL을 읽어서 HTML를 받아옴
headers = {
  'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)AppleWebKit/537.36 (KHTML, like Gecko) Chrome/73.0.3683.86 Safari/537.36'
}
data = requests.get('https://www.imdb.com/chart/top/?ref_=nv_mv_250', headers=headers)

# HTML을 BeautifulSoup 패키지로 검색하기 용이한 상태로 만듦
# soup 변수에 "파싱 용이해진 html"이 담긴 상태가 됨
# 코딩을 통해 필요한 부분을 추출하면 됨
soup = BeautifulSoup(data.text, 'html.parser') # html.parser는 파이썬 내장 HTML 파서다. HTML을 계층 구조로 분석해서 태그를 쉽게 찾아서 다룰 수 있도록 변환한다.
print(soup)
```

headers 작성 이유
- 봇 감지 우회
    - 많은 웹사이트는 자동화된 봇(스크래퍼)을 감자하고 차단하려 함
    - `requests` 모듈을 사용하면 기본 User-Agent(`python-requests/...`)가 포함되는데, 이는 쉽게 차단될 수 있음.
- 브라우저에서 접속한 것처럼 보이면 정샂억인 응답을 받을 확률이 높아짐
- 모바일과 데스크톱에 따라 다른 페이지를 보여줄 수 있다.
    - 따라서 원하는 형식의 데이터를 받기 위해 `User-Agent`를 맞춰줄 필요가 있음

#### 3. beautifulSoup4 사용법

> CSS 셀력터와 거의 동일함

- CSS 선택자를 크대로 사용할 수 있음
- 직접 선택자 `>`, 인접 선택자 `+`, 일반 형제 선택자 `~` 지원함
- CSS 의사 클래스 지원하지 않음 (`:contains`)

```python
# 선택자를 사용하는 방법
soup.select('태그명')
soup.select('.클래스명')
soup.select('#아이디명')

# 한 엘리먼트에 클래스명이 여러 개 존재한다면? 예: <div class"btn color-primary"></div>
# .btn.color-primary 이렇게 작성해 .btn을 가진 태그 중 .color-primary를 갖고있는 태그만 찾을 수 있다.
# 조건이 겹치지 않는다면, 마지막 클래스만 작성한다.
# 좀 더 구체화해서 찾고자하는 태그를 정확하게 타겟하기 위함
soup.select('상위태그명 > 하위태그명 > 하위태그명')
soup.select('상위태그명.클래스명 > 하위태그명.클래스명')

# 리스트와 같이 여러 태그가 반복될 때 원하는 태그를 몇 번째 자식인지 명시해 지정할 수 있음
soup.select('.클래스명:nth-child(자식의순서)')

# 태그와 속성값으로 찾는 방법
soup.select('태그명[속성="값"]')

# 한 개만 가져오고 싶은 경우
soup.select_one('위와 동일')
```
