## State

> State란 컴포넌트 내부에서 바뀔 수 있는 값을 의미함

- state의 변화 전, 후의 `메모리 주소`를 비교해 리렌더링 여부를 판단한다. (변화가 있으면 리렌더링)
- 불변성을 지켜주며, 값을 수정해야한다.
    - 참조 타입의 경우 메모리가 변경되지 않고 값이 변경되기 때문에, 직접 수정을 가하지 않고 새로운 메모리에 데이터가 할당되도록 하는게 중요하다. (얕은 비교)
    - 그렇지 않으면, 리렌더링이 일어나지 않음

```javascript
import React, { useState } from 'react';

function App() {
  const [dogs, setDogs] = useState(["말티즈"]);

  function onClickHandler() {
    // spread operator를 이용해서 dogs를 복사함
    // 메모리가 달라지는 새로운 배열을 생성한 것
    setDogs([...dogs, "시고르자브종"]);
  }

  console.log(dogs);

  return (
    <div>
      <button onClick={onClickHandler}>버튼</button>
    </div>
  )
}
```
