## 순수 함수

순수 함수(Pure Function)는 입력값이 같으면 항상 같은 결과를 반환하고,<br/>
함수 내부의 외부 상태를 변경하지 않는 함수를 의미함.

> 같은 입력 -> 같은 출력 = `f(x) = x + 1`

#### <순수 함수 예시>

```javascript
function add(a, b) {
  return a + b; // 같은 입력값이면 항상 같은 결과를 반환
}
```

#### <비순수 함수 예시>

```javascript
let total = 0;

function addToTotal(value) {
  total += value;
  return total; // 입력 값이 동일해도 실행할 때 마다 다른 결과가 나올 수 있음
}
```

## 리액트에서 순수 함수가 중요한 이유

### 1. 리액트 컴포넌트는 기본적으로 순수 함수여야 함

React의 함수형 컴포넌트는 기본적으로 순수 함수처럼 동작해야 함

#### <컴포넌트 순수 함수 예시>

```javascript
function Greeting({ name }) {
  return <h1>Hello, {name}</h1>;
}
```

#### <컴포넌트 비순수 함수 예시>

```javascript
let count = 0;

function Counter() {
  count += 1;
  return <p>Counter: {count}</p>;
}
```

```javascript
const [user, setUser] = useState({ name: "Alice", age: 25 });

const handleClick = () => {
  user.age = 26; // 메모리 자체에서 변경이 일어나서 주소에 변화는 일어나지 않음 
  setUser(user); // 따라서, React가 변경을 감지하지 못함
};
```

### 2. React 성능 최적화 관련

React에서는 불필요한 리렌더링을 방지하기 위해 `React.memo`, `useCallback`, `useMemo` 등을 사용할 수 있는데, 이 최적화 기법들이 제대로 동작하려면 순수 함수여야 함

```javascript
const Greeing = React.memo(({name}) => {
  return <h1>Hello, {name}!</h1>
});
```

- `name`이 변경되지 않으면 불필요한 리렌더링을 방지함
