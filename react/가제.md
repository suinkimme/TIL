## React란?

> JavaScript를 이용해서 웹, 앱 애플리케이션의 UI를 구축하는 도구

- SPA 기반의 프론트엔드 개발 프레임워크
- 컴포넌트 단위의 독립적인 블록을 이용한 개발 방법을 이용함

## SPA(Single Page Application) 아키텍처

### 정의

한 개의 페이지로 이루어진 애플리케이션이며 MPA(Multi Page Application)와 상반된 개념이다

### SPA 장점

- 딱 한개의 페이지로 구성된 웹 앱이다.
- 서버에 1회 리소스를 요청한다.
- 그 이후 필요할 때, 데이터만 받아와 '수정' 하는 방식으로 화면을 수정한다.
- 깜빡임 없는 자연스러운 UX를 구현할 수 있다.

### SPA 단점

SEO(Search Engine Organization)에 약하다. <br/>
검색 엔진(로봇)이 찾을 수가 없다.

```html
<html>
<head>
  <title>리액트 프로젝트</title>
  <link rel="stylesheet" href="app.css" type="text/css">
</head>
<body>
  <div id="app"></div>
  <script src="app.js"></script>
</body>
</html>
```

SEO를 위해서는 HTML 페이지 전체가 필요하다.
