## React란?

> JavaScript를 이용해서 웹, 앱 애플리케이션의 UI를 구축하는 도구

- SPA 기반의 프론트엔드 개발 프레임워크
- 컴포넌트 단위의 독립적인 블록을 이용한 개발 방법을 이용함

## SPA(Single Page Application) 아키텍처

### 정의

한 개의 페이지로 이루어진 애플리케이션이며 MPA(Multi Page Application)와 상반된 개념이다

### SPA 장점

- 딱 한개의 페이지로 구성된 웹 앱이다.
- 서버에 1회 리소스를 요청한다.
- 그 이후 필요할 때, 데이터만 받아와 '수정' 하는 방식으로 화면을 수정한다.
- 깜빡임 없는 자연스러운 UX를 구현할 수 있다.

### SPA 단점

SEO(Search Engine Organization)에 약하다. <br/>
검색 엔진(로봇)이 찾을 수가 없다.

```html
<html>
<head>
  <title>리액트 프로젝트</title>
  <link rel="stylesheet" href="app.css" type="text/css">
</head>
<body>
  <div id="app"></div>
  <script src="app.js"></script>
</body>
</html>
```

SEO를 위해서는 HTML 페이지 전체가 필요하다.

## React Component

> 컴포넌트를 통해 UI를 재사용이 가능한 개별적인 여러 조각으로 나누고, 각 조각을 개별적으로 살펴볼 수 있다. <br/> 개념적으로 컴포넌트는 JavaScript 함수와 유사하다.

- 컴포넌트는 `HTML` return 하는 함수다.
- `props`를 화면에 표시하는 React 엘리먼트를 반환한다.

### 함수형과 클래스형

#### 1. 함수형 컴포넌트 (권장)

```javascript
function Welcome(props) {
  return <h1>Hello, {props.name}</h1>;
}
```

#### 2. 클래스형 컴포넌트

```javascript
class Welcome extends React.Component {
  return() {
    return <h1>Hello, {this.props.name}</h1>;
  }
}
```

#### 함수형 컴포넌트를 권장하는 이유

1. 클래스형 컴포넌트 보다 **더 적은 코드**로 동일한 기능을 구현할 수 있다.
    - 클래스에서는 `this`를  사용하고, 메서드를 바인딩해야 했다.
2. Hooks를 사용할 수 있다.
    - React 16.8에서 도입되었고, 상태 관리와 생명주기 메서드를 쉽게 다룰 수 있다.
3. 가독성과 유지보수성 향상상 (2번 === 3번)
    - 클래스형은 `this`를 관리하고, 라이프사이클 메서드가 분산되어 있어 코드의 가독성이 낮아짐
4. 성능 최적화 (React의 내부 최적화)
    - 함수형 컴포넌트는 React의 Reconciliation(재조정) 과정에서 최적화가 더 잘 됨.
    - React의 Concurrent Mode와 Suspense 등의 새로운 기능이 함수형 컴포넌트에서 더 효과적으로 동작함.
5. 클래스형의 복잡한 개념 제거 (2번 === 5번)
6. 미래 React 업데이트와의 호환성성

## JSX

> JavaScript를 확정한 문법<br/>JavaScript의 모든 기능이 포함되어 있고, React Element를 생성하기 위한 문법

- JSX 문법을 사용해서 React 요소를 만들고 DOM에 렌더링 시켜서 그린다.
- JSZX는 React 요소다.

## Props

> 컨포넌트 간의 정보 교류 방법

- props는 반드시 위에서 아래 방향으로 흐른다. `부모 -> 자식`(단방향)
- props는 읽기 전용으로 취급하고, 변경하지 않는다.

### prop drilling

부모 -> 자식 컴포넌트간 데이터 전달이 이루어지는 방법이 props다.<br/>
부모 -> 자식 -> 그 자식 -> 그 자식의 자식 3번이나 데이터를 내린다. 이걸 바로 `prop drilling`, prop가 아래로 뚫고 내려간다. 라고 함.

### Props Children

```javascript
import React from 'react';

function user(props) {
  return <div>{props.children}</div>
}

function App() {
  return <User>안녕하세요</User>;
}
```

위 예제가 children props를 보내고 받는 방식이며, Layout 컴포넌트를 만들 때 자용 사용한다.
